Entry for [One Word for Your Wi-Fi on make.fun](https://make.fun/bounty/u-tuan-muda-one-word-for-your-wi-fi-a1b4fd72).

One word that describes my Wi-Fi, chosen by scoring ten candidate words on the
judge's five criteria — on-subject fit, the instant laugh, truth to how home
Wi-Fi actually behaves, freshness of the angle, and standing alone as a single
word — weighted 5/4/3/2/1 in the judge's own order.

The winning word: **Ghosted** (30/30). Full bars a second ago, gone now, no
explanation, no goodbye — the signal ghosts you exactly like a date.

## Run

```sh
node main.ts
```

Writes the winning word to `/output/entry.txt` and re-reads it to validate
the gate: UTF-8 text, 1–20 characters, not only whitespace, a single word.
